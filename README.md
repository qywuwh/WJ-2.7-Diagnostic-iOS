# WJ 2.7 Diagnostic — исходный код iOS

Нативное приложение SwiftUI/CoreBluetooth для Jeep Grand Cherokee WJ/WG 2.7 CRD. Это адаптация [JeepWJDiag](https://github.com/takyonxxx/Jeep_Grand_Cherokee_WJ_2.7_CRD_OBD-II_Diagnostic/) под проверку AutoHelfer BLE. Исходный проект распространяется по GPL-3.0; эта адаптация также распространяется по GPL-3.0. См. `LICENSE` и историю исходного репозитория.

## Состояние

В проекте есть проверенная референсом логика K-Line ECM/TCM, J1850 модулей, DTC и Live Data. В этом варианте включены экран подключения, DTC и ELM327 Console/Log. Управление исполнительными механизмами убрано из меню первого релиза. BLE GATT Explorer показывает сервисы, характеристики, свойства, RSSI и MTU; TX/RX можно выбрать вручную, UUID сохраняются для адаптера. Реальный AutoHelfer и автомобиль **не тестировались в этой сборке**. Успешная компиляция и получение ответа `ATI` пока не подтверждены.

Поддержка по исходной реализации: ECM, TCM и ряд J1850 блоков. Наличие конкретного блока и правильность его ответа следует подтверждать на автомобиле. Графики, избранные параметры, CSV поездки и автоматическое переподключение в этой адаптации не завершены. Интерфейс частично остаётся англоязычным.

## Сборка на GitHub без Mac

1. Создайте **свой публичный GitHub репозиторий** и загрузите в его корень содержимое этой папки, включая `.github/workflows/ios-build.yml`. Сохраните лицензию GPL-3.0 и исходный код доступными пользователям приложения.
2. Откройте вкладку **Actions** → **Build unsigned iPhone IPA** → **Run workflow**.
3. После успешной сборки откройте запуск и скачайте артефакт `WJ-Diagnostic-unsigned-IPA`. Внутри архива будет `WJ-Diagnostic.ipa`.
4. Этот IPA **не подписан**. Для установки на iPhone используйте SideStore или Sideloadly на Windows с бесплатным Apple ID по инструкциям выбранного инструмента. Возможность установки и срок действия подписи зависят от правил Apple и инструмента.

GitHub Actions использует macOS runner и `xcodebuild`, затем помещает `.app` в `Payload/` и создаёт IPA. Сертификаты, платный Apple Developer Program и Mac пользователя для сборки не требуются. Workflow публикует Actions Artifact, а не GitHub Release.

## Первая проверка на iPhone

1. Включите зажигание и вставьте AutoHelfer. Подключите iPhone по BLE в приложении.
2. Откройте **BLE Diagnostics / GATT**. Проверьте service UUID, TX/RX, Notify и состояние. При ошибке автовыбора выберите TX и RX вручную.
3. В **Консоль** отправьте `ATI`. Сохраните полный лог и BLE отчёт. Пока ответ ELM327 не получен, диагностику блоков не считайте подтверждённой.
4. Далее проверьте ECM, затем TCM и только затем J1850. Сравните DTC и Live Data с WJdiag Android на том же автомобиле.

Исходные последовательности и карты данных сохранены из референсного проекта; не добавляйте непроверенные команды записи. Команды консоли отправляются напрямую, поэтому используйте её только для известных безопасных запросов.

## Архитектура

`ELM327Connection` управляет BLE/WiFi транспортом, GATT, очередью ELM команд, таймаутами и логом. `KWP2000Handler`, `WJDiagnostics` и `LiveDataManager` реализуют протоколы и данные Jeep. SwiftUI экраны находятся в `Sources/Views`. Разделение BLE и ELM в разные самостоятельные типы остаётся задачей дальнейшего рефакторинга.
